# Cyberwave Radio — pedidos para o índice de músicas completas
#
# Coloque aqui as músicas que você quer que toquem completas no Catálogo do site.
# O GitHub procura o vídeo certo de cada uma na próxima execução (a cada 15 minutos) e o site passa a
# tocá-la inteira — inclusive no computador da empresa (AVD).
#
# Uma por linha. Linhas que começam com # são ignoradas. Formatos aceitos:
#
#   Artista - Música
#   Artista - Música | https://www.youtube.com/watch?v=XXXXXXXXXXX     (fixa este vídeo para a música)
#   https://www.deezer.com/br/playlist/1234567890                       (todas as músicas da playlist)
#   https://www.deezer.com/br/album/1234567                             (todas as músicas do álbum)
#   https://www.deezer.com/br/artist/1234                               (as 25 mais ouvidas do artista)
#   https://www.deezer.com/br/track/123456789                           (uma música)
#
# Exemplos (apague o # do começo para usar):
# Bring Me The Horizon - Kingslayer
# Sleep Token - The Summoning
